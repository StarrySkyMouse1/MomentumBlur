# 无人值守回放渲染任务实施计划

**依赖设计：** `../specs/2026-08-03-unattended-render-tasks-design.md`  
**交付策略：** review-first；复用现有检查，不默认新增测试工程。

## 批次 1：MTV 目录与持久化基础

- 实现 MMTV 版本化解析器，读取地图、玩家、赛道、阶段、成绩、记录时间、统计与预期回放信息。
- 扫描 `momtv/local` 和 `momtv/online`，生成稳定的记录目录模型并处理损坏/不支持版本。
- 引入 SQLite，创建任务、节点、日志与应用运行会话表；实现事务化仓储、队列排序和崩溃状态规范化。
- 定义任务配置快照、任务/节点状态机和合法状态转换。
- 验证：解析本机 local/online 样本，数据库重启恢复，Core 编译与现有 SmokeTest。

## 批次 2：任务页面配置、队列与历史

- 新增“任务”导航页及 ViewModel，提供配置、执行队列和历史视图。
- 实现四级树、单阶段单选、父节点选择状态、成绩排序、详情预览和任务分组创建。
- 实现待执行任务排序、删除、配置快照更新、运行中追加及历史文件操作。
- 所有破坏性文件删除显式区分；原始 `.mtv` 永不进入删除路径。
- 验证：独立代码审阅，使用本机记录库手工验证树、分组、排序、持久化和重启恢复；WPF 编译。

## 批次 3：游戏控制与执行状态机

- 实现 Momentum 进程所有权、自动启动、NetCon 连接/命令协议、控制台日志采集和受控关闭。
- 将现有 TGA 编排抽成可由手动合成页与任务执行器共同调用的节点录制服务。
- 实现前置检查、地图切换、`.mtv` 回放、暂停/复位、startmovie/endmovie、还原和完成信号聚合。
- 实现两次自动重试、失败暂停、完成节点后暂停、立即停止、继续、游戏崩溃恢复及动态队列消费。
- 验证：短线性 replay、单阶段 replay、模拟超时、立即停止、应用重启和游戏崩溃场景。

## 批次 4：无重编码合并与完成交付

- 在 Native API 中新增多段 H.264 MP4 流合并接口，仅重建容器和时间戳，不解码重编码，不修改源片段。
- 实现 `.merging.mp4`、轨道/时长验证、原子改名、成功后片段清理和失败后手动合并状态。
- 完成耗时、大小、重试、节点统计和每任务文本日志。
- 对照设计独立审阅并修复阻塞项；运行 Core、App、SmokeTest、Native 编译及真实多阶段短任务冒烟。

## 集成约束

- 各批次完成后单独提交，保持工作区无无关改动。
- 不引入 FFmpeg，不注入或修改 Momentum 游戏文件，不依赖鼠标键盘自动化。
- 数据库迁移必须保留既有设置和历史；应用升级时不得自动删除任务、日志、片段或输出视频。
- 若运行时证据表明 NetCon 无法提供某个完成事件，先停在该批次更新设计，不用固定延时静默替代。
