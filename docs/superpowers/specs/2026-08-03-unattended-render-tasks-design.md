# 无人值守回放渲染任务设计

**日期：** 2026-08-03  
**状态：** 产品行为已确认

## 1. 目标

在现有 WPF 应用中新增“任务”页面。程序扫描 Momentum Mod 已有 `.mtv` 回放，按用户勾选结果创建持久化队列，自动启动并控制游戏，在 TGA 模式下依次录制完整回放；线性地图输出一个 MP4，阶段地图按阶段顺序无重编码合并为一个 MP4。支持无人值守运行、动态追加任务、暂停、立即停止、失败重试、崩溃恢复、耗时统计和历史查询。

## 2. 已确认产品规则

- 任务功能仅在 TGA 模式下可用；监视目录必须已配置、存在且可访问。
- 程序自动启动 Momentum Mod；全部任务结束后自动关闭其启动的游戏实例。失败暂停时保留现场。
- 回放来源为游戏目录下 `momentum/momtv/local` 与 `momentum/momtv/online` 的 `.mtv` 文件。
- 配置树固定为“地图 → 玩家 → 完整地图/阶段 → 具体记录”。具体记录按成绩从快到慢、同成绩按日期从新到旧排列。
- 每个完整地图或阶段只能选择一条记录；创建任务后执行器严格使用保存的选择，不再推断阶段连续性或地图总阶段数。
- 同地图的不同玩家、主赛道与 Bonus 分别创建任务。一个任务最终对应一个 MP4。
- 每个 replay 从头到尾完整播放，不指定或裁剪 tick。
- 线性地图为单节点；阶段地图每个阶段为一个节点，按阶段编号升序执行。
- 新任务追加到队尾；运行中可继续创建任务；仅待执行任务允许调整顺序。
- 任务创建时保存设置快照。尚未执行的任务可显式更新为当前设置。
- 当前节点失败自动重试两次；仍失败则暂停队列，保留游戏和日志。
- 支持“完成当前节点后暂停”和“立即停止”。立即停止删除当前节点半成品，继续时从 replay 开头重录；已完成节点保持不变。
- 程序异常退出后恢复任务、节点和队列状态；当前未完成节点从头执行。
- 阶段片段合并采用 Media Foundation H.264 流直接合并，不重新编码。合并过程只读片段并写 `*.merging.mp4`。
- 最终文件验证成功后才原子改名并删除阶段片段。中断或合并失败时保留片段。
- 合并失败的任务标记为“片段完成，等待手动合并”，队列继续执行。
- 最终文件名为 `地图名_玩家名_YYYYMMDD_HHmmss.mp4`，并清理 Windows 非法字符。
- 删除任务永不删除原始 `.mtv`。历史记录默认不删除最终 MP4；“删除任务及输出文件”需要二次确认。

## 3. 页面与交互

左侧新增“任务”导航页，包含配置、执行队列和历史三个视图。

### 配置

- 显示 TGA 模式、游戏目录、监视目录、输出目录和磁盘空间前置检查。
- 扫描并解析 `.mtv`，显示四级选择树、父节点全选/半选状态和记录详情。
- 显示选择摘要、节点数、预计 replay 时长、将创建的任务与输出名称。
- 点击“创建任务”后按地图、玩家和赛道分组并追加队尾。

### 执行队列

- 显示任务顺序、地图、玩家、节点进度、状态、本次耗时和累计耗时。
- 支持开始、完成当前节点后暂停、立即停止、继续、重试当前节点和跳过当前节点。
- 待执行任务支持上移、下移、移到队首、移到队尾和删除。
- 展开任务显示节点状态、重试次数、中间文件和日志摘要。

### 历史

- 显示完成时间、最终状态、总耗时、输出大小和路径。
- 支持打开输出、打开日志、按原配置重新创建、删除记录、删除记录及输出。
- “等待手动合并”的任务支持打开片段目录。

## 4. 数据与状态

使用单个本地 SQLite 数据库保存：

- `RenderTask`：地图、玩家、赛道、队列位置、状态、配置快照、输出路径、累计耗时与错误摘要。
- `RenderNode`：回放路径、阶段、顺序、状态、重试次数、中间文件、开始/结束时间与耗时。
- `TaskLog`：时间、级别、任务、节点、状态转换和消息。

状态主线：

`待执行 → 启动中 → 执行中 → 合并中 → 已完成`

异常状态：`暂停`、`失败待处理`、`片段完成等待手动合并`、`已取消`。

任务另写可直接查看的文本日志；数据库仅存文件路径，不存 `.mtv` 或 MP4 内容。

## 5. 自动化与可靠性

- 通过 `momentum.exe`、本机随机 NetCon 端口和随机密码控制游戏，不模拟鼠标键盘。
- 保存程序拥有的游戏 PID 与 NetCon 会话信息；重启时只接管可验证归属的实例。
- 状态机依次完成地图加载、回放加载与复位、TGA 监视、录制、回放结束、TGA 排空、Native 收尾、节点验证和还原。
- 完成判断综合 NetCon/控制台状态、`.mtv` 元数据、TGA 文件活动和 MP4 轨道/时长验证，不使用固定延时作为成功条件。
- 地图加载、连接、回放启动、首帧、回放结束、排空和编码分别设超时与结构化错误。
- 所有输出先写任务临时目录；只有验证成功的最终 MP4进入成片目录。
